# NHSE for Mac — 本机网页版本

双击 `start.command`，浏览器会打开 `http://127.0.0.1:8765`。终端窗口保持打开时工具可用；关闭终端或按 Control-C 会停止服务。如果旧版工具已运行，请先关闭之前的终端，再重新启动。第一次双击若被 macOS 拦截，可右键 `start.command` 选择“打开”。

当前支持：读取 NHSE 支持的动森存档；编辑玩家和岛屿的基础字段、村民常用属性、DIY 配方状态，以及口袋、背包、仓库和回收箱的原始物品格数据。物品参数沿用 NHSE 核心的数值格式。其他 Windows 版专用编辑器，例如地图绘制、设计图、邮件、成就和图形物品选择器，尚未移植。

保存时生成新存档文件夹，放在 `publish/edited-saves/`，不会覆盖原存档。工具使用项目旁 `NHSE-master/NHSE.Core` 的解密、哈希和重新加密代码。网页服务只监听本机地址。

存档文件夹需包含 `main.dat` 与 `mainHeader.dat`。可在页面选择本机存档、点击“选择文件夹…”打开 macOS 文件夹选择窗口，或直接粘贴带单引号/双引号的路径。网页会在本机浏览器记住上次成功打开的路径。物品格会按物品类型显示可用数量或工具耐久字段。保存前应退出游戏；新存档需要由用户自行导入，工具不会替换游戏正在使用的存档。

## 分享与开发

仓库忽略本机 `.dotnet` SDK、构建输出和本地生成的存档。分享源码时不需要上传这些文件；使用者需要安装 .NET 10 SDK。此项目复用上级目录 `NHSE-master/NHSE.Core`，从 GitHub 克隆时需把原版 `NHSE-master` 放在 `NHSE-Mac` 旁边。`start.command` 会在发布文件缺失或源码更新时自动构建。

这个版本的村民“口头禅”是可见且可编辑的游戏属性，保留在常用字段中。

开发者手动重建：`./.dotnet/dotnet publish NHSE.Web.csproj -c Release -o publish`。
